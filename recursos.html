Módulo 5: Checklist de Despliegue y Recursos

✅ Checklist de Seguridad para Producción

📚 Glosario Rápido

  • Front Controller: Patrón donde una sola entrada (index.php) maneja todas las peticiones.
  • SQL Injection (SQLi): Inyección de código SQL malicioso a través de inputs no sanitizados.
  • XSS (Cross-Site Scripting): Inyección de scripts maliciosos en páginas web vistas por otros usuarios.
  • CSRF: Engañar a un usuario autenticado para que ejecute acciones no deseadas.
  • Salting: Añadir datos aleatorios a una contraseña antes de hashearla para evitar ataques de diccionario (PHP lo hace automático en password_hash).

🛠️ Herramientas Recomendadas

  • Composer: Gestor de dependencias de PHP (imprescindible para proyectos reales).
  • PHPStan / Psalm: Analizadores estáticos de código para encontrar errores antes de ejecutar.
  • Xdebug: Extensión para depuración paso a paso y análisis de rendimiento.
  • Postman / Insomnia: Para probar APIs y endpoints sin depender del frontend.
