Módulo 3: Seguridad Web y Autenticación

3.1 Hashing de Contraseñas (Nunca guardar texto plano)

PHP ofrece funciones nativas optimizadas. Se recomienda Argon2id (disponible en PHP 7.3+) o, en su defecto, Bcrypt.

// REGISTRO (Hashing)
$plainPassword = $_POST['password'];
// Argon2id es el estándar actual. Si no está disponible, usa PASSWORD_DEFAULT (Bcrypt)
$hash = password_hash($plainPassword, PASSWORD_ARGON2ID, ['memory_cost' => 2048, 'time_cost' => 4, 'threads' => 3]);
// Guardar $hash en la BD (NUNCA el password original)

// LOGIN (Verificación)
if (password_verify($_POST['password'], $userFromDb['password_hash'])) {
    // Contraseña correcta
    session_regenerate_id(true); // Previene Session Fixation
    $_SESSION['user_id'] = $userFromDb['id'];
    $_SESSION['role'] = $userFromDb['role'];
} else {
    // Mensaje genérico: "Credenciales inválidas" (no revelar si el usuario existe o no)
}

🕵️‍♂️ Caso de Hackeo: Cross-Site Request Forgery (CSRF)

Un atacante engaña a un usuario autenticado para que envíe un formulario sin saberlo (ej: un email con una imagen que apunta a tusitio.com/delete_account.php). Como el navegador envía las cookies de sesión automáticamente, la acción se ejecuta.

🛡️ La Defensa: Tokens CSRF

Genera un token único por sesión y valídalo en cada POST.

// 1. Generar token al iniciar sesión o cargar el formulario
if (empty($_SESSION['csrf_token'])) {
    $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
}

// 2. Incluir en el formulario HTML
<input type="hidden" name="csrf_token" value="<?= $_SESSION['csrf_token'] ?>">

// 3. Validar al procesar el POST
if (!hash_equals($_SESSION['csrf_token'], $_POST['csrf_token'])) {
    die("Error de seguridad: Token CSRF inválido.");
}

3.2 Prevención de XSS (Cross-Site Scripting)

Nunca confíes en lo que el usuario envía. Al mostrar datos en HTML, usa siempre htmlspecialchars.

// INCORRECTO (Vulnerable a <script>alert('hack')</script>)
echo "<p>Bienvenido, " . $_GET['name'] . "</p>";

// CORRECTO
echo "<p>Bienvenido, " . htmlspecialchars($_GET['name'], ENT_QUOTES, 'UTF-8') . "</p>";

3.3 Validación Robusta (La Regla de Oro)

Valida siempre en el servidor. La validación en JS es solo para UX.

function validarEmail($email) {
    return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
}

function validarCedula($cedula) {
    // Ejemplo: Solo números, entre 7 y 8 dígitos
    return preg_match('/^[0-9]{7,8}$/', $cedula) === 1;
}
