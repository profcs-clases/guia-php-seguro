2.1 ¿PDO o MySQLi?

Ambos son seguros si se usan correctamente, pero PDO es el estándar profesional moderno.

2.2 El Patrón Singleton para la Conexión

Evita abrir múltiples conexiones innecesarias. Garantiza una única instancia de la base de datos en toda la aplicación.

class Database {
    private static $instance = null;
    private $pdo;

    private function __construct() {
        $dsn = "mysql:host=" . DB_HOST . ";dbname=" . DB_NAME . ";charset=utf8mb4";
        $options = [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_EMULATE_PREPARES => false, // ⚠️ CRUCIAL: Desactiva emulación para seguridad real
        ];
        $this->pdo = new PDO($dsn, DB_USER, DB_PASS, $options);
    }

    public static function getInstance() {
        if (self::$instance === null) self::$instance = new self();
        return self::$instance;
    }
    
    public function query($sql, $params = []) {
        $stmt = $this->pdo->prepare($sql);
        $stmt->execute($params);
        return $stmt;
    }
}

🕵️‍♂️ Caso de Hackeo: SQL Injection Clásico

Si concatenas strings: "SELECT * FROM users WHERE id = " . $_GET['id']

Un atacante envía: ?id=1 OR 1=1. La consulta se convierte en SELECT * FROM users WHERE id = 1 OR 1=1, devolviendo todos los usuarios.

🛡️ La Defensa: Consultas Preparadas

PDO separa la estructura de la consulta de los datos. El motor de BD compila el SQL primero y luego inserta los datos como valores literales, no como código ejecutable.

// FORMA SEGURA
$db = Database::getInstance();
$stmt = $db->query("SELECT * FROM users WHERE email = :email", ['email' => $_POST['email']]);
$user = $stmt->fetch();

2.3 Transacciones (Commit / Rollback)

Esencial para operaciones que modifican múltiples tablas (ej: registrar usuario y su perfil). Si una falla, se deshace todo.

try {
    $pdo->beginTransaction();
    $pdo->query("INSERT INTO users (name) VALUES (?)", ['Juan']);
    $pdo->query("INSERT INTO profiles (user_id, bio) VALUES (?, ?)", [1, 'Dev']);
    $pdo->commit();
} catch (Exception $e) {
    $pdo->rollBack(); // Deshace los cambios si algo falla
    error_log("Error en transacción: " . $e->getMessage());
}
