Módulo 4: Arquitectura por Capas y Temas Avanzados

4.1 Flujo MVC Simplificado

  1. Router: index.php recibe /usuarios/crear.
  2. Controlador: UserController.php recibe la petición, valida el CSRF y los datos del POST.
  3. Modelo: Llama a UserModel->create($data) para interactuar con PDO.
  4. Vista: El controlador carga views/usuarios/crear.php pasando solo los datos necesarios para pintar.

4.2 Control de Acceso por Roles (Middleware)

Un "Middleware" es un código que se ejecuta antes de llegar al controlador principal.

// app/Middleware/AuthMiddleware.php
function requireRole($allowedRoles) {
    session_start();
    if (!isset($_SESSION['user_id'])) {
        header("Location: /login.php");
        exit;
    }
    if (!in_array($_SESSION['role'], $allowedRoles)) {
        http_response_code(403);
        die("Acceso denegado: No tienes permisos suficientes.");
    }
}

// Uso en el Controlador:
requireRole(['admin', 'editor']);
// ... resto de la lógica del controlador ...

4.3 Depuración Profesional (Debugging)

En producción, nunca muestres errores al usuario. Usa logs.

// config.php (Producción)
ini_set('display_errors', 0); // No mostrar en pantalla
ini_set('log_errors', 1);     // Guardar en archivo
ini_set('error_log', __DIR__ . '/../storage/logs/php_errors.log');

// En tu código, atrapa excepciones y logéalas:
try {
    // código riesgoso
} catch (PDOException $e) {
    error_log("Fallo en BD: " . $e->getMessage() . " en " . $e->getFile());
    // Mostrar mensaje amigable al usuario
    echo "Ocurrió un error inesperado. Nuestro equipo ha sido notificado.";
}

ℹ️ Sección de Cultura Profesional (Informativa)

Los siguientes temas no son parte de la evaluación obligatoria del curso, pero dominarlos te dará una ventaja competitiva masiva en tu primer empleo:

  • Git Workflow: Nunca trabajes en la rama main. Crea feature/nombre-funcionalidad, haz commits atómicos y usa Pull Requests.
  • Variables de Entorno (.env): Nunca subas config.php con contraseñas a GitHub. Usa librerías como vlucas/phpdotenv para cargar credenciales desde un archivo .env que está en .gitignore.
  • Testing Básico: Usa la función nativa assert() para validar que tus funciones devuelven lo esperado antes de desplegar. assert(calcularTotal(10, 5) === 15);
  • 2FA (Autenticación de Dos Factores): Para sistemas críticos, implementa TOTP (códigos de 6 dígitos tipo Google Authenticator) usando librerías como spomky-labs/otphp.
